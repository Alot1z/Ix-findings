# AGENTS.md — Ix-findings

Repository-level rules for any agent (AI or human) working here.

## No attribution footers — ever

Commit messages, PR descriptions, issue bodies, and comments must never carry
tool/agent attribution. Do NOT include any of the following, in any casing
variation:

- `🤖 Generated with Codebuff`
- `Generated with Codebuff 🤖`
- `Co-Authored-By: Codebuff <noreply@codebuff.com>`
- Any `Co-authored-by:`, `Co-Authored-By:`, `Generated by:`, or `AI:` line
- Any mention of the tool, agent, or model that produced the work

Commit messages are plain conventional-commit text: a summary line, a blank
line, then the body. No footer block, no attribution, no tool branding.

## GitHub write policy

- Only Ix-findings may be modified via this repository.
- Never push to upstream `ix-infrastructure/Ix` or any unrelated repository.
- No GitHub writes (issues, PRs, labels, comments, reviews, merges, reactions,
  branch mutations) without explicit per-action user authorization.
- PR/issue comments, when authorized, are technical navigation indexes only:
  no narrative, no authorship language, no AI attribution.

## Data integrity

- The canonical knowledge layer (`knowledge/`) is the source of truth.
  Regenerate derived artifacts with:
  `node knowledge/build-knowledge.mjs && node planning/wiki/build-data.mjs && node planning/pages/build-public.mjs`
  and validate with `node planning/pages/validate-public.mjs`.
- Do not fabricate filenames, symbols, line numbers, commits, or relationships.
  If exact references cannot be verified, say so explicitly.
- Preserve existing UI design; data and routing changes only.
