## Reconciliations made in this phase (summary)

1. **Phases are numbered 0–12** in the existing ledger (not 1–13); the archive
   below uses the existing numbering to stay link-compatible, and adds
   `phase-13` (push/PR gate, pending) and `phase-final` (this phase).
2. **Finding IDs**: the ledger uses `IXF-###`; the planning registry assigns
   parallel `F-###` IDs (1:1 mapping documented in `findings/registry.md`).
3. **Decision IDs**: the ledger uses `DEC-###`; the planning registry assigns
   `D-###` (1:1 for DEC-001…009, plus D-010…014 for the still-open plan.md
   decisions D1–D5).
4. **Release-date contradiction**: `manifests/artifact-sha256.json` lists
   v0.1.0/v0.1.1/v0.2.0 `release_date` as 2026-08-07/08; three other documents
   (release timeline, repository map, investigation index) corroborate
   2026-03-28 / 03-29 / 06-08. The August values are treated as recovery dates;
   the March/June dates are the reconciled release dates (see
   `overview/timeline.md` and `final/verification.md`).
5. **Zoom multiplier**: phase-07 observed `×1.25` on the zoom-in button while
   the artifact constant analysis says `×1.1`. Recorded as an open unknown
   (F-013, class D — see `findings/registry.md`).
6. **Sanitization**: raw local paths found in `decisions/log.md` and
   `repositories/repository-map.md` were replaced with placeholders
   (`<IX_REPO>`, `<IX_REMAP_WORKTREE>`, `<COMPASS_DIST_REPO>`, `<IX_FINDINGS>`,
   `<SANITIZED_ROOT>`). No other evidence was modified.
