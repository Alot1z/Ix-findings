INJECTIVITY
-----------
sanitizeId is injective over UTF-16 code-unit encounters:
  / -> ~2F, ? -> ~3F, : -> ~3A, NL -> ~0A, TAB -> ~09, SP -> ~20,
  % -> ~25, ~ -> ~7E
  . allowed, but leading "." encoded as ~2E (collision-free)
  Each UTF-16 code unit is encoded or passed through; surrogate pairs are two
    code units each encoded individually; UTF normalization is NOT applied; a
    U+00E9 (NFC) cafe-@E9 and a cafe+@301 (NFD) encode to DIFFERENT filenames.
    This is acceptable: identical byte-sequences produce identical filenames;
    visually identical names with different normalization are DISTINGUISHED
    on disk, not collapsed.

ATTACK-SURFACE NOTES

    cannot be confused with an encoding.
